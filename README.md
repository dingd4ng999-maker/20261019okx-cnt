<h2 style="font-size:27px;line-height:1.5">五、OKX KYC 為什麼會失敗？怎麼提高通過率？</h2>

<p>KYC 失敗最常見的問題通常集中在證件、姓名、照片和人臉辨識幾個環節。</p>

<h3 style="font-size:23px;line-height:1.6">1. 姓名與證件不一致</h3>

<p>帳戶填寫的姓名應和身分證件保持一致，不要自行使用暱稱、不同拼寫或他人姓名。</p>

<h3 style="font-size:23px;line-height:1.6">2. 證件已經過期</h3>

<p>應使用仍處於有效期限內的證件。</p>

<h3 style="font-size:23px;line-height:1.6">3. 證件照片模糊或反光</h3>

<p>拍攝時確保：</p>

<ul>
<li>證件邊緣完整；</li>
<li>文字清晰；</li>
<li>沒有嚴重反光；</li>
<li>沒有被手遮擋；</li>
<li>沒有經過修改或美化。</li>
</ul>

<h3 style="font-size:23px;line-height:1.6">4. 人臉辨識失敗</h3>

<p>進行人臉辨識時，建議在光線充足的環境操作，並避免：</p>

<ul>
<li>戴墨鏡；</li>
<li>帽簷遮擋臉部；</li>
<li>鏡頭模糊；</li>
<li>環境過暗；</li>
<li>使用他人的臉部完成驗證。</li>
</ul>

<div style="border:1px solid #ddd;border-left:6px solid #d9534f;background:#fafafa;padding:20px 22px;margin:26px 0;border-radius:8px">
<strong>⚠️ 不要使用他人身分資料進行 KYC</strong><br>
OKX 帳戶、身分證明、人臉認證和後續付款資訊應保持本人一致。使用虛假資料可能影響帳戶認證、資金操作和後續帳戶恢復。

<h2 style="font-size:27px;line-height:1.5">九、OKX 第一次交易怎麼操作？</h2>

<h3 style="font-size:23px;line-height:1.6">Market Order 市價單</h3>

<p>市價單會按照目前市場中可取得的價格盡快成交。</p>

<p>適合希望快速成交的情況，但需要注意：</p>

<p><strong>市價單可能出現滑點。</strong></p>

<p>特別是在流動性較低或市場劇烈波動時，最終平均成交價格可能與下單瞬間看到的價格不同。</p>

<h3 style="font-size:23px;line-height:1.6">Limit Order 限價單</h3>

<p>限價單允許自己設定願意買入 BTC 的價格。</p>

<p>例如 BTC 目前為 80,000 USDT，而你只希望在 78,000 USDT 買入，就可以掛出 78,000 USDT 的限價買單。</p>

<p>優點是可以控制價格，缺點是：</p>

<p><strong>如果市場沒有到達設定價格，訂單可能一直無法成交。</strong></p>

<p>對於第一次交易的新用戶，可以先使用較小金額熟悉下單、撤單、訂單歷史和資產變化。</p>
